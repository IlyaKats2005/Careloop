## Publish the prepared files

From the repository root, authenticate and push:

```sh
gh auth login --hostname github.com --git-protocol https --web
gh auth setup-git
git push https://github.com/IlyaKats2005/Careloop.git main
```

After that push, the video file is available at:

https://github.com/IlyaKats2005/Careloop/blob/main/docs/demo/Careloop-Demo.mp4

## Finish Devfolio

1. Upload `Careloop-Demo.mp4` to a supported video host. Devfolio prefers YouTube; an unlisted upload lets judges watch via its link.
2. Sign in to [the TUM Devfolio event](https://tum.devfolio.co/) as the **team admin** and edit the existing Careloop project.
3. Paste the actual hosted video URL into **Video Demo**. Add the repository and live-app links from [DEVFOLIO.md](../DEVFOLIO.md), and select the Cardano track.
4. Use the prepared project description, check the required fields, click **Publish Project**, and verify **Submitted** on the dashboard.

A source push, a video upload and a Devfolio submission are three separate steps. This document records the prepared deliverables; it does not claim that Devfolio has been submitted.

Sources: [event submission requirements](https://hackathon.tum-blockchain.com/prizes#how-to-submit), [Devfolio submission guide](https://guide.devfolio.co/docs/guide/participating-in-hackathons/project-submission).
